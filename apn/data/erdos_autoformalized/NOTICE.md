# The Erdős-autoformalized dataset

18 Erdős problems formalized by our own autoformalization pipeline — **not**
vendored from upstream `google-deepmind/formal-conjectures` (FC), unlike the
other datasets here. The problems were chosen precisely because they were
absent from FC at the pipeline's FC pin.

Upstream source: the 18 `.lean` files in the root of
`epoch-research/autoformalization` `results/2026-08-25-erdos-target-run/`
(pipeline repo commit `c7a4bf4` at run time), vendored verbatim into
`Sources/` on 2026-08-26. That directory's `raw/README.md` documents the run:
statements were generated by `anthropic/claude-fable-5` and
`openai/gpt-5.6-sol` and passed through a multi-model adjudication gate frozen
on a held-out FC calibration set. The vendored root files differ from the
run's gated `raw/submit/`+`raw/hold/` output only in shipping-form cleanup
already applied upstream of this repo: the Apache/FC banner prepared for FC PR
submission dropped, `answer(sorry) ↔` forms rewritten to plain `P`, and
linter `set_option` lines removed.

Problem 1020 is included on the same footing as the other 17 even though the
run's gate held it back (the models disputed the problem's *decomposition*,
not the formalization, which adjudication-compiled like the rest); this
dataset records no gate distinction.

`fc_commit` pins the FC commit the pipeline compiled these files against
(Lean toolchain `v4.27.0`). Since nothing here is vendored *from* FC, the pin
plays only its runtime role: it keys the sandbox images and fixes the
`FormalConjecturesUtil` proving library (+ Mathlib) version the statements
import.

`samples.jsonl` lists every research-category statement in those files — one
per `@[category research ...]` theorem, so the two two-part files (713, 1206)
contribute two members each: 20 members over 18 problems.
