# The Erdős dataset

Upstream source: the 48 `FormalConjectures/ErdosProblems` files hosting Thomas Bloom's statement selection, at the FC commit pinned in `fc_commit` (certified statement-identical to the review commit by `scripts/erdos_statement_certificate.py`). `samples.jsonl` censuses every research-category statement in those files; `subsets/bloom_selection.json` names the 47 scoreable selected statements, `apn_erdos`'s default. See `metadata/ERDOS_PROBLEM_STATEMENT_SELECTION.md` for the details of Bloom's selection.
